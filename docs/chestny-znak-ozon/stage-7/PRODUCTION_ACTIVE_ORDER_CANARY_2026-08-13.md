## JIT и этикетка

Узкий allow-list JIT/labels включен только для
`D16-TSH-PRT-WGRY-XL`. Заказ `0141094663-0075-1` имел заготовку, принт и
свободный КМ, поэтому для него создано назначение
`06bf6000-03b0-42e2-b434-c75351d54ef2`.

КМ перешел в `reserved + emitted`, склад при резерве не изменялся. Этикетка
`getomerch-58x40-v1` сформирована один раз, имеет точный размер `58 x 40 мм`,
повторно декодирована из PDF и побайтно совпала с исходным КМ СУЗ.

Подтверждение физического нанесения, складское производство, ввод в оборот и
передача экземпляра в Ozon не выполнялись.

## Складские блокировки

Оставшиеся шесть заказов пока не получили assignment:

- для четырех серых вареных футболок размера S отсутствуют четыре пустые
  заготовки;
- для бежевой вареной футболки размера XL отсутствует одна пустая заготовка;
- для белой обычной футболки размера XXL отсутствует одна пустая заготовка в
  цехе вышивки;
- для двух заказов `D16-TSH-PRT-WGRY-S` в учете есть только один принт,
  поэтому после добавления заготовок потребуется еще один принт D16.

Пять оставшихся GTIN имеют шесть свободных КМ `available + emitted`. Их нельзя
назначать в обход складского gate: сначала фактические остатки должны быть
внесены в админку.

## Безопасность и flags

После импорта `GETOMERCH_MARKING_IMPORT_ENABLED=false`. Внешние записи ГИС МТ,
СУЗ и Ozon, ввод/вывод, возвраты и automation остаются выключенными.
`GETOMERCH_MARKING_JUST_IN_TIME_ENABLED` и
`GETOMERCH_MARKING_LABELS_ENABLED` включены только с offer allow-list
`D16-TSH-PRT-WGRY-XL`.

Временные TXT, PNG и серверные копии перезаписаны и удалены. Исходные PDF СУЗ
и итоговая заказная этикетка сохранены локально с правами `0600` и должны
считаться конфиденциальными документами с полными КМ.

## Следующий gate

1. Физически изготовить `D16-TSH-PRT-WGRY-XL`.
2. Напечатать заказную этикетку без масштабирования и нанести на товар.
3. Только после подтверждения нанесения выполнить складскую транзакцию,
   подписать `LP_INTRODUCE_GOODS`, дождаться `in_circulation` и передать
   экземпляр в Ozon.
4. Для остальных заказов сначала актуализировать склад, затем выполнить такой
   же JIT-процесс по одному КМ на единицу.
