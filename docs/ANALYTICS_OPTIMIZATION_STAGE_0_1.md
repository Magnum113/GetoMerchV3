# Оптимизация аналитики: этапы 0–1

## Цель

Ускорить загрузку дашборда без сокращения истории, показателей, таблиц или строк в API.

## Этап 0. Зафиксирован расчётный контракт

- Контрольная дата: `2026-09-10T12:00:00.000Z`.
- Проверяются пресеты `7 дней`, `30 дней`, `90 дней`, `месяц`, `год`.
- Для каждого пресета проверяются графики с шагом `день`, `неделя`, `месяц`.
- Полный снимок включает KPI, предыдущий период, финансовые графики, заказы и выручку по заказам, невыкуп, структуру расходов и топ товаров.
- Отдельно проверяется стоимость остатков по каждому складу и итоговая сумма.
- Проверка не использует production-БД и воспроизводима локально.

Команда:

```bash
npm run check:analytics-baseline
```

Эталон: `tests/fixtures/analytics/dashboard-baseline.json`.
Стандартный `getomerch-deploy-from-git` запускает эту проверку до production-сборки и не активирует релиз при расхождении.

## Этап 1. Устранена лишняя работа при загрузке

- При смене периода незавершённые запросы предыдущего периода отменяются.
- Повторный запрос того же периода использует уже выполняющуюся загрузку.
- Старый полный набор данных остаётся на экране, пока новый период не загрузился целиком.
- Дата на экране всегда относится к фактически показанным данным.
- Отмена устаревшего запроса не показывается пользователю как ошибка.
- Постраничные загрузчики прекращают обход страниц сразу после отмены.
- JSON-ответы размером от 1 КБ сжимаются Nginx (`gzip`, уровень 5).

Конфигурация Nginx хранится в `ops/nginx/getomerch-json-compression.conf`. Она должна быть подключена только внутри HTTPS `server` для `admin.komui.ru`:

```nginx
include /etc/nginx/snippets/getomerch-json-compression.conf;
```

После установки обязательны `nginx -t`, reload и проверка, что авторизованные API-ответы на запрос с `Accept-Encoding: gzip` содержат `Content-Encoding: gzip`.

## Граница этапов

Этапы 0–1 не меняют SQL, пагинацию, формулы аналитики и объём доступных данных. Агрегирующий серверный endpoint и сокращение повторяющихся объектов относятся к следующему этапу.
