# Инструкция по составлению артикулов KOMUI

Документ описывает единый шаблон артикулов для товаров KOMUI. Брендовый префикс не используется. Версии макета в артикуле НЕТ — разные версии одного визуала считаются разными дизайнами (разный код `D#`).

## 1. Общий принцип

Артикул однозначно описывает товарную вариацию:

- дизайн;
- носитель;
- тип нанесения;
- цвет;
- размер.

Для худи дополнительно указываются посадка и ткань.

## 2. Шаблон для футболок и свитшотов

```text
DESIGN-GARMENT-DECOR-COLOR-SIZE
```

Пример:

```text
D16-TSH-PRT-WGRY-M
```

Расшифровка:

```text
D16   - код дизайна
TSH   - футболка
PRT   - принт
WGRY  - вареный серый
M     - размер
```

## 3. Шаблон для худи

```text
DESIGN-HDY-DECOR-COLOR-FIT-FABRIC-SIZE
```

Пример:

```text
D2-HDY-EMB-BLK-REG-FLC-M
```

Расшифровка:

```text
D2    - код дизайна
HDY   - худи
EMB   - вышивка
BLK   - черный
REG   - обычная посадка
FLC   - с начесом
M     - размер
```

## 4. Коды сегментов

### DESIGN

Код дизайна — `D` + число без ведущих нулей: `D1, D2, … D16, … D20`. Задаётся один раз и не меняется при переносе на другой носитель, цвет или размер.

Один и тот же визуал, нанесённый принтом и вышивкой — это один код дизайна (различие принт/вышивка кодируется сегментом DECOR). Но РАЗНЫЕ версии макета (перерисованный принт) — это РАЗНЫЕ коды дизайна (например серый Сатору v1 = `D16`, v2 = `D20`).

### GARMENT

```text
TSH - футболка
HDY - худи
SWT - свитшот
```

### DECOR

```text
PRT - принт
EMB - вышивка
```

### COLOR

```text
BLK  - черный
WHT  - белый
WGRY - вареный серый
WBEG - вареный бежевый
WBLU - вареный синий
BLU  - синий обычный
```

Новый цвет — новый короткий код в том же стиле (`GRN`, `RED`, `NVY`…).

### FIT (только худи)

```text
REG - обычное худи
CRP - укороченное худи
```

### FABRIC (только худи)

```text
FLC - с начесом
NF  - без начеса
```

### SIZE

```text
XS S M L XL 2XL 3XL
```

Используем `2XL`/`3XL`, а не `XXL`/`XXXL`.

## 5. Примеры

```text
D16-TSH-PRT-WGRY-M          футболка, принт, вареный серый, M
D4-TSH-EMB-WHT-L            футболка, вышивка, белый, L
D2-SWT-EMB-BLK-XL          свитшот, вышивка, черный, XL
D2-HDY-EMB-BLK-REG-FLC-M   худи, вышивка, черный, обычная посадка, с начесом, M
D18-HDY-EMB-BLK-CRP-NF-L   худи, вышивка, черный, укороченная, без начеса, L
```

## 6. Правила для новых товаров

1. Определи дизайн. Новый визуал ИЛИ новая версия макета существующего — новый код `D#`.
2. Носитель: `TSH` / `HDY` / `SWT`.
3. Нанесение: `PRT` / `EMB`.
4. Цвет: существующий код или новый в справочник.
5. Для худи добавь посадку и ткань (`REG-FLC`, `REG-NF`, `CRP-FLC`, `CRP-NF`).
6. Размер.

## 7. Чеклист

- Дизайн уже существует или нужен новый `D#`? (новая версия макета = новый код)
- Носитель указан верно?
- Принт и вышивка не перепутаны?
- Цвет соответствует фактическому товару?
- Для худи указаны посадка и ткань?
- Размер в стандартном формате (`2XL`, не `XXL`)?
- Такой артикул ещё не существует?

## 8. Хранение и идентичность

Источник истины артикула — атрибуты товара в `merch_products` (категория, нанесение, цвет, размер, дизайн-код, для худи посадка/ткань). Артикул генерируется из них. Идентичность товара — `sku` (артикул) + `ozon_sku` (стабильный числовой Ozon SKU). Старые артикулы хранятся в `legacy_skus` для матчинга исторических заказов.
